# C Programming

A practical repository where I am learning and practicing C from the basics, with a focus on writing clear code and understanding how things work at a lower level.

The goal is to build a solid C foundation before moving on to Embedded C and firmware development.

## Topics

- Variables and data types
- Operators and expressions
- Input and output
- Conditional statements
- Loops
- Functions
- Arrays and strings
- Pointers
- Structures, unions and enums
- Memory and storage classes
- Preprocessor and header files
- Modular C programming
