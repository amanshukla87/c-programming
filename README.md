# C for Embedded Systems

A practical C programming repository focused on building a strong foundation for embedded systems and firmware development.

I am using this repository to practice C, understand how the language works at a lower level, and gradually connect these concepts with microcontrollers and embedded development.

## What I am working on

- C fundamentals
- Control flow and functions
- Arrays and strings
- Pointers
- Structures, unions and enums
- Memory and storage
- Bitwise operations
- Preprocessor and header files
- Modular C programming
- Embedded C concepts
